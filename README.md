# Gerry-Lee Snelling — Portfolio

Space-themed portfolio with dual modes: **WORK** (moon) and **LIFE** (sun).

## Features

- WORK / LIFE mode toggle with separate themes, photos, and content
- English / Japanese language switch
- Project showcases with modals
- Blog section
- Animated star particles and orbital photo frame
- Responsive and mobile-friendly

## File Structure

```
├── index.html
├── styles.css
├── main.js
├── particles.js
├── cv-en.pdf
├── cv-ja.pdf
└── images/
    ├── photo-pro.png
    ├── photo-personal.png
    ├── screenshot1–7.png
    ├── piano.png, lion.png, fuji.png, reader.png
```

## Setup

Static site — no build tools needed. Open `index.html` or deploy to any hosting (GitHub Pages, Netlify, etc).

## Tech

HTML / CSS / Vanilla JS / Font Awesome / Google Fonts
